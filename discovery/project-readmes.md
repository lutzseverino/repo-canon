# Discover Project README scope

The source's Project README guidance, `guidance/project-readmes.md`, defines a
Project. Inspect the complete repository evidence for Projects: manifests,
workspace and build configuration, existing documentation, maintained source,
and meaningful component boundaries. Directory names and conventional layouts
alone do not establish membership.

Propose one individual non-root `README.md` path for every Project. Include an
existing README when present. For a missing README, include its intended path
with absence evidence and positive evidence for the Project. Do not propose
directory trees, globs, the root README, exact-owned files, or paths owned by
another declaration.
