# Delegation and session naming

Before handing work, including subwork and heavy reads, to another agent,
subagent or session, check whether an installed skill covers it. Invoke the
covering skill with task context; when none covers it, pass task context only.
Keep procedure and question format with the invoked skill.

Task context includes issue links, evidence, recorded decisions, scope,
workspace and plan references, report-back destinations and task-specific
delivery obligations.

Where supported, name sessions you launch or own for their operation and
target, outside invocations and task context; otherwise continue unnamed.
