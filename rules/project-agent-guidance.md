# Project agent guidance rules

The optional `docs/agents/project.md` holds only repository-specific agent
constraints. It exists only when there are useful constraints to state.

Keep installed rules, `CONTRIBUTING.md`, and the skill setup files as the
sources of their shared requirements; do not restate them here.

The shared `AGENTS.md` is a map of work moments to authoritative files. Its
start-of-work entry reaches installed rules through the Repository Standards
skill, including for work that changes no file. The optional project page
adds only the repository's constraints, not a second rules-lookup procedure.
