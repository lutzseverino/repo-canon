# Glossary map

## Contexts

- [Repo Canon](GLOSSARY.md): standards, adoption, and boundaries shared with the
  host-installed factory.
- [Factory](factory/GLOSSARY.md): providers, run outcomes, and factory releases.

## Relationships

Repo Canon and the factory share the host configuration and factory
configuration boundary, while keeping independent releases. The root glossary
holds those boundary terms and Pull request reviewer; the factory glossary
holds its internal language. System-wide decisions stay in `docs/adr/`;
factory-local decisions live in `factory/docs/adr/`.
