Git ancestry · quick reference

Release baseline guard

A graph-reachability decision; no history changes

Question: Is the required baseline an ancestor of the candidate release commit? Do not infer the answer from commit dates.

Command

git merge-base --is-ancestor "$baseline" "$candidate"

First argument: the commit that must be contained. Second argument: the candidate being tested.

Exit-status policy

  • 0 — baseline is an ancestor of candidate: permit the release.
  • 1 — baseline is not an ancestor: reject the candidate normally.
  • Other nonzero — Git could not complete the check: stop and report an error.

Shell pattern

if git merge-base --is-ancestor "$baseline" "$candidate"; then
  # eligible
else
  status=$?
  if [ "$status" -eq 1 ]; then
    # ineligible
  else
    # error: stop
  fi
fi

Source: official git-merge-base documentation. See lesson 0001 for practice.
