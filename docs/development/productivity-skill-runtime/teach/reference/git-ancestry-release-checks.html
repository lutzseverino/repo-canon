Quick reference · Git ancestry

Does the candidate contain the baseline?

Ask whether the required baseline is an ancestor of the candidate release commit.

git merge-base --is-ancestor <baseline> <candidate>

The first commit must be reachable from the second by following parent links.

Result contract

  • Status 0 — baseline is an ancestor of candidate: the candidate contains it.
  • Status 1 — baseline is not an ancestor of candidate: the candidate does not contain it.
  • Any other non-zero status — Git could not perform the check: stop and surface the error; do not treat it as “not contained.”

Safe shell shape

git merge-base --is-ancestor "$baseline" "$candidate"
status=$?
case "$status" in
  0) printf '%s\n' 'baseline is contained' ;;
  1) printf '%s\n' 'baseline is not contained' ;;
  *) printf '%s\n' 'ancestry check failed' >&2; exit "$status" ;;
esac

Guardrail

Do not infer ancestry from timestamps. “Earlier” describes a clock reading; ancestor describes reachability through parent links.
