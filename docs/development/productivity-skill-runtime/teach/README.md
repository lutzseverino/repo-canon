# Retained teaching workspace

This directory preserves the files produced by the `teach` exercise. The
[mission](MISSION.md), [resources](RESOURCES.md), and [glossary](GLOSSARY.md)
record learning state. Supporting directories retain the shared
[asset](assets/), [lesson](lessons/), [reference](reference/), and
[learning records](learning-records/).

The directory indexes are Repo Canon evidence navigation added after the
exercise; they are not presented as `teach` output.
