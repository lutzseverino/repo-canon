## Agent Brief

**Category:** enhancement
**Summary:** Let operators export Delivery receipts for one UTC calendar date as CSV.

**Current behavior:**
The repository contains the Parcel operations glossary and local tracker only;
there is no Delivery receipt implementation or export capability yet.

**Desired behavior:**
An operator can request a CSV export for a selected UTC calendar date. The
export includes Delivery receipts whose delivered timestamp falls within that
UTC date, with one row per receipt. It has columns for the Parcel reference,
delivered timestamp, signer name, and delivery status, in that order. The
delivery status contains the final delivered status. Delivered timestamps in
the output remain ISO 8601 UTC values. Rows are ordered by Parcel reference.
When the selected date has no Delivery receipts, the result is a valid CSV
containing those headers and no data rows.

**Key interfaces:**
- The operator-facing Delivery receipt export capability: accept one selected
  UTC calendar date and return CSV data for that date.
- The Delivery receipt representation: provide the Parcel reference, delivered
  timestamp, signer name, and final delivered status required by each exported
  row.
- CSV output: expose exactly the four requested receipt fields in a stable
  column order while preserving CSV-valid values.

**Acceptance criteria:**
- [ ] An operator can obtain a CSV export for a selected UTC calendar date.
- [ ] The export contains one row for each Delivery receipt delivered from the
      start of that UTC date up to, but not including, the next UTC date, and
      excludes receipts outside that interval.
- [ ] Every data row contains the Parcel reference, ISO 8601 UTC delivered
      timestamp, signer name, and final delivered status, in that column order.
- [ ] Data rows are sorted by Parcel reference.
- [ ] A date with no matching Delivery receipts produces header-only, valid
      CSV.
- [ ] Automated tests cover a populated date, UTC date-boundary filtering,
      ordering, and the empty-date result.

**Out of scope:**
- PDF export.
- Scheduled or recurring delivery of exports.
