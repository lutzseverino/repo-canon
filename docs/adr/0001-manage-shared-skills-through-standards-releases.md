# Manage shared skills through standards releases

Status: the skills it manages are narrowed to workflow skills by
[ADR 0018](0018-install-only-workflow-skills.md).

The standards source owns reviewed, pinned snapshots of Matt Pocock's regular
skills and distributes updates through standards releases. This keeps adopting
repositories on inspectable versions and avoids conflicts between standards
ownership and independent skill updaters, at the cost of waiting for the
standards maintainer to review and release upstream changes. Adopting-project
contribution guidance therefore does not instruct contributors to update the
managed skill collection.
