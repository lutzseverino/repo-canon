# Documentation

This directory maps Repo Canon's documentation categories.

- [Usage](usage/README.md): using, configuring, and integrating the standards
  source, with durable research on those topics.
- [Development](development/README.md): building, testing, architecture, and
  maintenance of the source, with durable research on those topics.
- [Architecture decisions](adr/README.md): consequential decisions and their
  rationale.
- [Agent configuration](agents/README.md): shared agent workflow configuration
  and repository-specific agent constraints.
