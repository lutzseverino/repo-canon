# Documentation

Documentation is grouped by purpose. Create a category when it has content;
give each documentation directory a README describing its scope and linking
useful contents.

- [Usage](usage/README.md): using, configuring, and integrating the standards
  source.
- [Development](development/README.md): developing, testing, and maintaining
  the source.
- [Architecture decisions](adr/README.md): consequential choices and rationale.
- [Agent configuration](agents/README.md): shared workflow configuration and
  repository-specific guidance.

Place durable research findings with their usage or development topic. The
[root glossary](../CONTEXT.md) defines the domain language; the
[authoring notes](../authoring-notes.md) hold this source's confirmed decisions
and their rationale. The [third-party notices](../THIRD_PARTY_NOTICES.md)
identify redistributed material and its licenses.
